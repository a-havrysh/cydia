# Legacy iOS Tweaks — Cydia repo

A single Cydia source aggregating MobileSubstrate tweaks for jailbroken
legacy iOS devices (iOS 6+). This repo is a pure distribution point — no
source code lives here. Each tweak's source lives in its own repo and
publishes its built `.deb` here automatically via CI on every release.

## Add this source in Cydia

Sources → Edit → Add → `https://a-havrysh.github.io/cydia/`

## Repo layout

```
Packages / Packages.gz   dpkg-scanpackages index over debs/, regenerated by CI
Release                  repo metadata
CydiaIcon.png             repo icon
debs/                    built .deb files, pushed here by each source repo's CI
```

## Publishing a new tweak here

In the tweak's own repo:

1. Build the `.deb` (see that repo's README) into `dist/`.
2. Add a `.github/workflows/publish.yml` that, on push to `main` when `dist/`
   changes, checks out this repo with a `CYDIA_PUSH_TOKEN` secret (a PAT with
   `contents:write` on this repo), copies `dist/*.deb` into `debs/`, reruns
   `dpkg-scanpackages debs /dev/null > Packages && gzip -k -f Packages`, and
   commits + pushes. See `kindle-sync-fix`'s workflow as a template.
3. Add a row to the table above.

Nothing here is edited by hand except this README and the icon — everything
under `debs/`, `Packages`, and `Packages.gz` is CI-managed.
